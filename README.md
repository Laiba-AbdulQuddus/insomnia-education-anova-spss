# Statistical Analysis of Insomnia Severity by Education Level (SPSS)

## Overview
This project investigates whether insomnia severity differs across education levels using statistical analysis in SPSS.

A survey dataset of 100 adult participants was analyzed using one-way ANOVA, assumption testing, and post-hoc analysis to examine relationships between education level and insomnia severity.

## Research Question
Does insomnia severity significantly vary across different education levels?

## Tools Used
- SPSS
- One-Way ANOVA
- Levene’s Test
- Games-Howell Post Hoc Test
- Descriptive Statistics
- Data Visualization (Histograms and Boxplots)

## Dataset
The dataset contains:
- Age
- Gender
- Education Level
- Athens Insomnia Scale (AIS) responses
- Computed total insomnia score

Sample Size:
- 100 participants

## Methodology
The analysis included:

1. Data cleaning and preparation in SPSS  
2. Computation of total insomnia scores  
3. Descriptive statistical analysis  
4. Assumption checks:
   - Normality
   - Homogeneity of variance
5. One-Way ANOVA
6. Games-Howell post hoc analysis
7. Effect size interpretation

## Key Findings
- No statistically significant difference in insomnia scores across education groups

ANOVA Result:

F(4,95) = 1.367  
p = 0.251

Effect Size:

η² = 0.054

Education level explained only 5.4% of variation in insomnia severity.
